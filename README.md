# Astra Client

Astra Client is a modern, lightweight launcher for **Minecraft: Java Edition**, written in Rust.

> **Status:** in early development. No public release yet.

## What it does

- Sign in with your **Microsoft account** (official OAuth flow in your system browser – your password never touches the launcher)
- Manage multiple, fully isolated Minecraft instances (versions, mod loaders, settings)
- Download game files directly from Mojang's official servers, verified by hash
- Show your current skin as a 3D model
- Show news about Astra Client

## What it does not do

- No cracked or offline-mode accounts – a legitimate copy of Minecraft: Java Edition is required
- No redistribution of Minecraft game files or Mojang assets
- No collection or sharing of account tokens – tokens stay encrypted on the user's own PC (Windows DPAPI)

## This repository

This repository is the project page and hosts the downloads. New versions will appear under **Releases** once the first version is published; each release lists the SHA-256 checksum of its download.

## Platforms

Windows x64 (other platforms planned).
